## Resolucion final del bug de streaming

El problema era que el proxy `api.selectapi.vip` responde con `stream: false` si se le pide streaming pero no funciona bien, o el formato de chunks no era el esperado.

**Solucion aplicada:**
1. Cambiar `stream: false` en `runChat()` para recibir respuesta completa
2. Leer toda la respuesta con `response.text()`
3. Parsear como JSON (respuesta no-streaming de Anthropic) o como SSE
4. Extraer `data.content[0].text` y enviar como SSE `type: "chunk"` al frontend

**Archivos cambiados:**
- `src/app/api/chat/route.ts` — modelo de env var + lectura completa + streaming adaptativo
- `src/app/api/analyze/route.ts` — modelo de env var
